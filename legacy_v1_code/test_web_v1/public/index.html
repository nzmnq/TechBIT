Управління вузлом ESP32-C3 та Базові рівні

Актуальна розпіновка ESP32-C3 SuperMini (PCB)

  • GPIO2 (ADC1_CH2): вихід підсилювача MCP6002 (R5/C4), у спокої ~1650 мВ
  • GPIO8 (SDA) / GPIO9 (SCL): датчик температури і вологості GY-SHT40 (роз'єм J3, 0x44)
  • Увага по GPIO8: синій світлодіод на платі SuperMini висить на GPIO8 — у прошивці блимання вимкнене при ENABLE_SHT40=1
  • GPIO21 (TX) / GPIO20 (RX): CAN-шина SN65HVD230 (500 kbps)
