# Архів попередньої версії TechBIT (v1)

Ця гілка (`legacy-v1-archive`) та папка `legacy_v1_code/` збережені як резервна копія попередньої версії коду до переходу на нову B2B IoT + SaaS архітектуру (Тягач + Причеп 10 коліс, осьові вузли `ESP32-C3`, місток `ESP-NOW`, хаб `ESP32-S3 Black Box + LTE + BLE`).

## Що тут збережено
- `legacy_v1_code/esp_v1/` — попередня версія PlatformIO-прошивки (1 вузол `ESP32-C3` на колесо, 512-pt FFT + TinyML MLP, 4-колісний CAN `0x100..0x113`, локальна модель у `ml_trainer/`).
- `legacy_v1_code/web_v1/` — попередній інтернет-магазин та API для легкових/2x/4x комплектів (без SaaS-підписки та моделі Тягач/Причеп).

Для переходу назад до активної розробки перемкніться на `esp-code` або `web-development`.
